# Aperfeiçoando a resolução de problemnas

Perguntas a serem feitas:

1. Quais os dados de entrada que terie? (inputs)
2. Quais as variáveis?
3. Qual o caminho ideal? (fluxo ideal)
4. Qual(is) o(s) caminho(s) alternativo(o)? (fluxo alternativo)
5. Quais tratamentos de dados preciso fazer? (estrutura de dados, funções)
6. Qual é a saída, ou quais os dados de saída, esperada? (outputs)

# Ferramentas de linguagem que abordamos

[] loop while
[] arrays e nfunções de arrays (.push)
[] condicional switch e if/else
[] template literals (strings)
